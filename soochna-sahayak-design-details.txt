10. PRINT / PDF STYLES
----------------------------------------------------------------

  Page size       A4 landscape (297mm x 210mm), margin 6mm
  Hidden on print All .no-print elements (navbar, form, buttons, overlay)
  Shown on print  All .print-only elements (vertical text spans, print name divs)

  Name inputs     Hidden (replaced by .att4-name-print div with static text)
  Delete buttons  Hidden
  Document        Transform reset, width 100%, no shadow, padding 6mm
  Row breaks      break-inside: avoid on all tr elements
